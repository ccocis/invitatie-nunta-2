# Wedding Invitation Website — Design Ideas

## Reference Analysis
The reference site (daniel-simina.netlify.app) is a Romanian wedding invitation with:
- Animated envelope with wax seal on the landing page
- Elegant off-white/cream background with gold accents
- Script fonts (Cormorant Garamond, Pinyon Script) mixed with clean sans-serif (Montserrat)
- White rose floral corner decorations
- Couple photo in a circular medallion
- Countdown timer to wedding date
- Event details with location cards
- Schedule/timeline
- RSVP form

**Design Movement:** Romantic Classicism — Regency-era stationery meets modern web elegance

**Core Principles:**
1. Every element should feel like it belongs on a physical invitation card — tactile, precious
2. Restraint over excess: one accent color (antique gold), one script font, one serif font
3. Whitespace as luxury — generous margins signal refinement
4. Animations should feel like physical objects moving (envelope opening, paper unfolding)

**Color Philosophy:**
- Background: warm ivory `#FAF8F4` — like aged parchment, not clinical white
- Text: deep charcoal `#2C2A27` — warm black, not cold
- Gold accent: `#C9A96E` — antique, not shiny/metallic
- Muted rose: `#E8D5C4` — for subtle dividers and borders

**Layout Paradigm:**
- Single-column centered layout with a defined max-width (like a physical card)
- Sections separated by decorative dividers (floral ornaments, thin gold lines)
- The envelope/card metaphor: the entire page feels like opening a letter

**Signature Elements:**
1. Wax seal SVG on the envelope landing screen with pulse animation
2. Floral corner SVG decorations (white roses/peonies) on the main invitation card
3. Thin gold ornamental dividers between sections

**Interaction Philosophy:**
- Click the wax seal → envelope opens with CSS 3D flip animation → invitation slides up
- Smooth scroll between sections
- RSVP form with elegant validation states

**Animation:**
- Envelope: 3D perspective flip (rotateX) revealing the invitation card
- Invitation content: staggered fade-in-up as sections appear
- Countdown: subtle number tick animation
- Floral decorations: very gentle sway on hover

**Typography System:**
- Display/Script: `Great Vibes` or `Pinyon Script` — for couple names and dates
- Serif body: `Cormorant Garamond` — for all body text, elegant and readable
- Sans-serif labels: `Montserrat` light/300 — for small caps labels, times, locations

- Scroll-triggered reveal of botanical elements

## Selected Design: Romantic Classicism (Response 1)

This approach most faithfully captures the reference site's aesthetic while bringing a refined, hand-crafted quality. The warm ivory palette, antique gold accents, and physical-object animations will create an invitation that feels precious and personal.
